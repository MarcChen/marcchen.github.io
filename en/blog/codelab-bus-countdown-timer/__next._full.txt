<h2>Bus Station Project: Enhancing Public Transport with IoT</h2>

<p>The <strong>Bus Station Project</strong> began as a personal solution to a common problem I faced while studying at Paris-Saclay. With only buses to travel between locations, I frequently encountered situations at the Place Marguerite Pery bus station, just in front of Telecom Paris, where no ETA (estimated time of arrival) was available. To know when to leave my house, I had to check the bus schedule on my phone each time before heading out. This sparked the idea to create a system that could provide real-time bus arrival times, making my commute more predictable and efficient.</p>

<p>The project focused on developing an IoT system specifically for my local bus station, with the aim of offering live bus arrival information for better timing. The core challenge wasn’t API integration, as the RATP API is well-documented, but rather connecting the ESP32 microcontroller to the public Wi-Fi network in my student housing. The Wi-Fi had a portal login page, which made it tricky. I used <strong>Wireshark</strong> to capture the network traffic from my computer when connecting through the portal, replicating the same process on the ESP32, which successfully worked.</p>

<h2>Development Overview</h2>

<p>The project entailed several components:</p>
<ul><li><strong>API Integration</strong>: Initially, we simulated real-time data using the <strong>RATP API</strong> to retrieve bus arrival times, which could be replaced by sensor-based data from actual bus stations in the future.</li>
<li><strong>Data Processing</strong>: The collected data was processed to predict bus arrival times. A countdown mechanism helped reduce the frequency of API requests, optimizing power consumption.</li>
</ul>
<h2>Key Contributions</h2>

<p>1. <strong>Power Optimization</strong>: A key improvement was the implementation of a countdown to manage API requests efficiently, reducing unnecessary power usage.</p>

<h2>Future Potential</h2>

<p>One future improvement would be to implement a schedule to manage power efficiency by automatically turning off the system during working hours when it is not needed. This would ensure that power is used only when the system is actively providing information.</p>
